面试

Coral · 跑通 demo 并上线试用 11/11 · 交付 11/20
跑通 demo 并上线试用：从创建项目到生成最终评估包，用一组演示数据在线上完整走一遍。
  1. 创建项目：上传 JD 和简历即可创建；只有面试协调人、用人经理、模块管理员能创建；文件夹、邮件导入入口隐藏
  2. 规划与排期：设置轮次和面试官，发送邀请；支持候选人选时间、面试官接受或拒绝、改期、换面试官
  3. 评分标准未确认时：仍可排期并提交总体结论，但逐项能力评分保持 Unknown§12 JD 与权限
  4. 独立评分：面试官提交评分卡前，看不到他人和 AI 的评分§12 AI 与人工差异
  5. 面试结论：用人经理和招聘结论确认人分别提交结论，协调人完成后生成最终评估包，可查看§12 独立闭环
  6. 暂缓 / 不推进 / 补证：都能完成本次评估，不自动新建轮次，不自动终止候选人申请§12 Hold/Reject
  7. 首页全部面试：字段、状态、跳转与设计稿一致（见已提交的 issue 清单）

简历筛选

Coral · 跑通 demo 并上线试用 11/13 · 交付 11/20
跑通 demo 并上线试用：上传简历 → 确认职位关联 → 筛选评估 → 决定下一步 → 下载筛选包，线上走通。
  1. 上传入库：批量上传，单份解析失败不影响其他，可单独重试SCR-06；只有简历没有职位也能入库SCR-25
  2. 重复与新版本：同一份简历改名重复上传不重复建档；同名不同人不自动合并，生成复核任务SCR-23/24
  3. 创建职位：上传文件或手动输入（含语音），自动识别职位名称、要求和薪资
  4. 职位推荐与关联：AI 推荐的职位须人工确认后才创建申请，确认后页面状态立即更新SCR-26
  5. 筛选评估：AI 初评分、覆盖率、匹配反馈都能定位到简历原文；未提供工作许可显示待核实，不自动拒绝SCR-02/03
  6. 决定下一步：推进到笔试 / 面试、暂缓、不推进、索取信息，原因必填；AI 建议推进但人工选暂缓时只保存暂缓SCR-05；「仅记录」不显示为推进面试
  7. 结果过期：简历或 JD 更新后，旧结果保留并提示重新评估SCR-07
  8. 筛选包：查看决策页可下载筛选包；邮件发送失败不撤销已确认的结果SCR-12

笔试

Shaogang · 跑通 demo 并上线试用 11/13 · 交付 11/20
跑通 demo 并上线试用：建项目 → 出题 → 邀请候选人 → 作答提交 → 评分 → 发布结果，线上走通。
  1. 创建项目与候选人：从 HireOS 导入或手动上传；可上传或手动添加候选人，多选批量发送
  2. 题库：可导入 ZIP、手动或 AI 创建题目；概念题不能直接发送ASM-FLOW-02
  3. 邀请与规则：邀请前写明 AI / 网络 / 开卷、时限和时区ASM-FLOW-04；候选人验证邮箱并接受后才能开始ASM-FLOW-03
  4. 作答提交：上传和保存草稿不算提交，明确提交并锁定后才生效ASM-FLOW-05
  5. 评分：评审人提交前看不到他人和 AI 的评分ASM-BLIND-01；必评项为 Unknown 时总分为空ASM-FLOW-07；人工改分保留原分和理由ASM-FLOW-08
  6. 结果发布：内部确认和发给候选人分开，未发布的结果候选人看不到ASM-FLOW-10；发布时必须明确达标或未达标ASM-RESULT-01
  7. 修订与重考：新开一轮作答，旧轮次保留ASM-FLOW-12
  8. 推进面试：交接失败时显示待交接，不回滚已确认的测评结果ASM-HANDOFF-01

JD 管理

Shaogang · 跑通 demo 并上线试用 11/13 · 交付 11/20
跑通 demo 并上线试用：创建职位 → 编辑 JD → 检查 → 提交审批 → 生效，线上走通。
  1. 创建职位：从笔记、文件、Copilot 对话等入口创建，AI 提取结构化内容，人工确认后生成草稿JD-01 · AC-01
  2. 协作编辑：两人同时改同一条要求时冲突可见，不静默覆盖；评论可回复和解决AC-02
  3. 检查：必填项缺失会阻止提交审批，选填项和建议不加门槛JD-CHECK-01
  4. 审批与生效：提交审批 → 审批 → 生效；重复点击只生成一个版本，未成功前不切换生效版本AC-06；已开放职位的重大修改需要重新审批AC-07
  5. 权限：普通成员不能通过 AI 读取受限薪资AC-03；薪酬按角色显示精确值、区间或不可见
  6. 内部与外部 JD：外部版只显示公开内容；内部生效和外部发布状态分开显示AC-17
  7. 职位库：列表、筛选和搜索可用JD-06；职位暂停、关闭后不能发起新的招聘动作AC-15

候选人端

Coral · 跑通 demo 并上线试用 11/13 · 交付 11/20
跑通 demo 并上线试用：候选人从邀请邮件进入，完成补资料、笔试作答和面试选时间，手机上走通。
  1. 没有自主投递入口：只能通过企业发出的邀请链接进入SCR-47
  2. 邀请链接：验证邮箱并接受后才能访问；链接过期、被撤销或邮箱不一致时有明确提示SCR-41
  3. 简历筛选补资料：可填写字段、上传文件、保存草稿，提交后有回执SCR-48
  4. 笔试：查看规则、开始作答、上传和保存草稿、正式提交，查看已发布的结果笔试 §6.1
  5. 面试：选择面试时间、提议其他时间、发起改期，查看本人场次的会议入口面试 §3.4.2
  6. 信息边界：看不到内部评分、评语和其他候选人的信息
  7. 手机可用：以上流程在手机浏览器上能完整操作

通用验收（所有模块）

  1. 登录与角色：邮箱验证码登录；按模块角色控制可见和可操作的内容；超级管理员能看到全部任务并有操作权限
  2. 首页我的任务：统计卡片可筛选列表，任务按截止时间排序、逾期标红；点整行进入处理页面；只统计人工任务SCR-32 · ASM-TASK-01
  3. 中英双语：切到中文后，除人名、邮箱、职位标题外没有残留英文
  4. 外观与导航：浅色 / 深色、大字号和 200% 缩放下主操作可用AC-14；每进入下一步都能返回上一步
  5. 异常处理：AI 不可用、文件解析失败、下游离线时显示明确错误并可重试，不伪造结果SCR-10 · AC-13
  6. 防重复：重复点击、重复上传、重复提交不会生成重复记录SCR-09 · AC-09
